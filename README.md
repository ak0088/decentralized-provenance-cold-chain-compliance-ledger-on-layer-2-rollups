## 📖 Overview
An immutable supply-chain tracking ledger leveraging Zero-Knowledge rollups and IoT cryptographic hardware signers to audit perishable pharmaceutical cold-chain handoffs with real-time temperature SLA enforcement.

This system was engineered as a capstone research project in **Blockchain & Decentralized Tech**, featuring a modular 5-tier architecture, robust error boundaries, and verifiable benchmarks.

## 🚀 Key Features
- **Modular 5-Tier Architecture**: Clean separation between presentation, ingestion, core logic, persistence, and output channels.
- **Robust Error Handling**: Graceful degradation and resilient queue buffering for uninterrupted availability.
- **Academic Rigor**: Complete milestone roadmap, threat matrix, and oral defense revision materials.
- **Empirical Validation**: Automated performance metrics and verifiable benchmark suite.

## 🛠️ System Layers
1. **1. Physical & Sensor Edge Layer** (`Hardware / Embedded`) — Physical sensor transducers and edge microcontrollers capturing environmental and telemetry signals in real time.
2. **2. Telemetry & Gateway Layer** (`Network / Ingestion`) — Lightweight, low-bandwidth communication protocols routing packets from field nodes to central services.
3. **3. Stream Analytics & Rules Engine** (`Real-Time Analytics`) — Continuous event evaluation, anomaly threshold detection, and automatic actuator command triggering.
4. **4. Time-Series & Historical Storage** (`Persistence / Time-Series`) — High-throughput append-only time-series persistence for telemetry alongside relational configuration tables.
5. **5. Monitoring & Actuation Dashboard** (`Presentation / Visualizer`) — Interactive monitoring console displaying live telemetry gauges, historical trends, and manual actuation overrides.

## 🚦 Getting Started

### Prerequisites
- Node.js (v18 or higher) or Python 3.10+ (depending on runtime)
- npm / yarn / pip

### Installation
```bash
git clone https://github.com/your-username/decentralized-provenance-cold-chain-compliance-ledger-on-layer-2-rollups.git
cd decentralized-provenance-cold-chain-compliance-ledger-on-layer-2-rollups
npm install
```

### Run Application
```bash
npm run dev
```
